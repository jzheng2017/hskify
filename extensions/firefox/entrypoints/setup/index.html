Install the local engine

Open the HSK Manga Translator Windows bundle and run Install.ps1. It installs the companion for your Windows account and registers it with Firefox.

  1. Close any older HSK Manga Translator companion process.
  2. Right-click Install.ps1 and run it with PowerShell.
  3. Return to Firefox and reopen the extension.

No port, API key, account, or server setting is required. Models remain on this computer.
